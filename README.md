# grand-pebble-kit

Software engineer @Ramp

日常脚本的集中地

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 为什么写

现有的工具都太重，就想要个能管道拼接的小东西。

## 安装

```bash
git clone https://github.com/USER/grand-pebble-kit.git
cd grand-pebble-kit
cargo build --release
```
